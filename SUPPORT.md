# Support

Semantic Detector is a research-oriented open-source project. Support is provided on a best-effort basis.

## Where to ask

- **Bug or regression**: open a Bug Report issue with a minimal reproducible input.
- **Feature request**: open a Feature Request issue and explain the protocol-analysis use case.
- **Security issue**: follow [SECURITY.md](SECURITY.md); do not paste sensitive traffic or credentials into a public issue.
- **Questions about data contracts or labels**: first check [docs/DATA_CONTRACT.md](docs/DATA_CONTRACT.md) and [docs/SEMANTIC_TAXONOMY.md](docs/SEMANTIC_TAXONOMY.md).

## What to include

Please include the Semantic Detector version or commit, Python version, operating system, command used, relevant configuration, and a sanitized minimal input whenever possible.

The project does not guarantee analysis accuracy for arbitrary protocols. Example metrics are demonstration results, not general performance claims.
