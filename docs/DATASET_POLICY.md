# Dataset and Trace Policy

Semantic Detector 的公开仓库只接收来源明确、使用权限清晰的数据。

## 可接受

- 明确允许研究/再分发的公开数据集；
- 协议规范或测试工具生成的合成流量；
- 无法再分发但可以公开下载的数据：仓库仅保留下载说明、来源、哈希和预处理脚本，不提交原始数据。

## 不接受

- 客户、学校横向项目或生产系统的未授权流量；
- 含账号、Token、Cookie、个人信息、私网拓扑、真实业务载荷等敏感内容的抓包；
- 来源不明、许可证不明或明确禁止再分发的数据。

## 每个公开数据集必须记录

- 原始来源 URL / DOI / 项目页；
- 获取日期；
- 许可证或使用条款；
- 是否允许再分发；
- 原始文件 SHA-256（条件允许时）；
- 从原始数据到 `messages.jsonl` 的预处理步骤；
- 任何过滤、抽样、去标识化或人工真值操作。

这些要求的目的不是增加手续，而是确保实验结果之后仍然可以被审计和复现。
